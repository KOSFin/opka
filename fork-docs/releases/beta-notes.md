Opka — экспериментальный форк Orca, не официальный релиз Orca.

- Mac arm64: `opka-macos-arm64.dmg`; ZIP предназначен для проверки release feed и переносимой установки.
- Linux x64: `opka-server-linux-x64.tar.gz` содержит runtime, Node и нативные зависимости. После распаковки запускайте `./opka-server`; по умолчанию доступ только через loopback. Для обычного подключения по SSH используйте встроенную установку runtime из Opka.
- `SHA256SUMS` и provenance JSON позволяют проверить целостность файлов и исходный коммит. Контрольная сумма не заменяет подпись разработчика.

Mac beta не имеет Developer ID и notarization. macOS может запросить явное разрешение на открытие приложения. Не отключайте Gatekeeper и не снимайте quarantine скриптами. Обновление: скачать установщик из Opka, дождаться проверки, открыть его, завершить только Opka и подтвердить замену `Opka.app`. Не заменять `Orca.app`. Данные профиля не входят в пакет и не удаляются при замене приложения.

Это ещё не production-релиз. Не используйте beta для единственной копии важных данных. Рабочая Orca, её профили и старые серверы не являются целями установки. Аккаунты автоматически не переносятся. Автоматическая регистрация user-global hooks отключена: Codex и управляемые аккаунты устанавливают hooks в собственные runtime homes; существующие настройки глобальных CLI не переписываются при старте.

В этом выпуске: обычный чат Opka может взять утверждённую карточку своей сессией, сохранять checkpoint/препятствия и отправить отчёт на Review. Отчёты доступны в карточке через Reports & notes. Done требует отдельной приёмки пользователя. В существующем проекте включите More actions → Enable agent task workflow, затем начните новый чат. Непривязанный внешний CLI не получает identity автоматически.

Исправлены выбор собственного CLI в терминалах, поиск задач из вложенной папки без Git и проверка обновлений при отсутствии более нового prerelease. При выборе ранее ненастроенного проекта доска перепроверяет каталог; уже настроенные переключения не получают нового полного сканирования.

Один настоящий Codex turn в синтетическом проекте подтвердил исправление кода, тесты, checkpoint/report и Review. Найденный на последнем UI-шаге дефект discovery исправлен и проверен отдельно без модели; первоначальный модельный E2E не объявляется полностью зелёным. Независимый AI-reviewer, автоматический Done, передача недоступного владельца и Engram не входят в выпуск. Полная E2E проверка типов содержит grandfathered ошибки; это не stable-релиз.

Версию, выполненные проверки и ограничения сверяйте с журналом итерации 6 и руководством fork-docs/guides/chat-task-lifecycle.md в исходниках этого релиза.
