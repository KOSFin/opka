## Границы

- Не менять рабочую Orca, старый сервер, аккаунты или корпоративные проекты для тестирования форка.
- Не устанавливать NetBird и не открывать runtime в интернет.
- CI build artifacts не являются подписанными установщиками. Канал обновлений, bundle identity, подпись и mobile delivery требуют отдельной подготовки.
- Автоматический полный цикл карточка → агент → независимое ревью → результат пока не объявляется реализованным.

## Журнал

После содержательных действий, решений, ошибок и пользовательских исправлений добавлять timestamp `Asia/Yekaterinburg` с `+05:00`, результат проверки и следующий шаг. Журнал append-only; текущий план и краткий checkpoint обновляются. Перед handoff/compaction сохранить незавершённые проверки. Исходники, сборка, runtime-проверка и публикация — разные результаты.
